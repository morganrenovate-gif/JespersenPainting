## Installation handoff (separately authorized project-scoped executor)

Bundle `private_runtime/hedy_financial_handler.cjs` with an installed local CommonJS-capable browser bundler, e.g. `esbuild private_runtime/hedy_financial_handler.cjs --bundle --platform=browser --format=iife --global-name=JespersenFinancial --outfile=financial-handler.js`. The resulting bundle exposes `JespersenFinancial.createHandler(dependencies)`; register its returned async function as the Hedy scheduled handler with a task-scoped staging event `{task:'PRIVATE-DATA-006',environment:'staging'}`. The adapter has no background network/client; it does not fetch configuration. Confirm Hedy's actual scheduled-function signature and size ceiling with the private executor before installing; bundle/minify to that ceiling. Do not install from this public lane.

Private executor supplies all `dependencies` inside the authorized staging project: `scope` with exact client/environment, root, explicit authority and kill-switch; `key` scoped to task/tenant/environment; durable transactional `store.get/cas/accept`; `transport.inventory/fingerprint/extractCells` backed by an authorized read-only XLSX decoder; independent `qa.verify`; private immutable outputs published only by the same atomic fenced checkpoint commit; and an independently approved set of exact shape `profiles`. No root/file/source ID, hash, workbook bytes, profile from a real workbook, configuration, credential, error text or runtime payload belongs in GitHub. Transport must enforce actual ancestry and read-only permissions itself, snapshot the original bytes and verify original-byte SHA-256 at **each** step. `fingerprint` returns `{sha256,signature}` and `extractCells` returns an exact profile-bound `{sha256,signature,complete,sections,totals,labels,nonempty}` cell snapshot. A cell has `{sheet,address,raw,formula,result}`; `result` is the separately read cached/evaluated formula result (never derived by this runner). `nonempty` is the complete inventory of all nonempty cell locators so unexpected cells/labels cannot disappear. An approved profile declares exact section headers, supported totals, and `labels`: an array of exact literal `{sheet,address,raw,formula:null,result:null}` header/metadata cells. The snapshot must reproduce those labels exactly, their locators join the complete nonempty inventory, and their source evidence is preserved. Arbitrary cells cannot be omitted or approved as wildcard metadata; unknown or partial layouts remain review work. Do not use the synthetic profile as real coverage. Private executor must independently validate any proposed real adapter/profile against source evidence before enabling it.

Store CAS must atomically compare revision and persist values across handler invocations and concurrent workers. `store.accept(key, revision, nextCheckpoint, outputKey, record, lease)` is mandatory: check lease expiry using the trusted runtime clock immediately before initiating the final commit. In one linearizable revision-fenced commit, compare checkpoint revision and lease owner, reject cancelled/revoked scope and conflicting existing output, publish immutable output and update the checkpoint together. Immutable output blobs staged before the commit are private unreferenced candidates; readers may resolve only outputs referenced by the committed head. Return `false` on stale revision/owner/cancellation without publishing accepted output; unreachable immutable staging blobs may remain for scoped cleanup. A separate `output.putIfAbsent` followed by checkpoint CAS does not meet this contract. Output is keyed by version/source/digest and retains provenance and independent source-bound QA receipt privately. A successful `cancel()` CAS fences every later acceptance transaction; transactions committed before cancellation remain auditable accepted output.

One durable queue-wide lease serializes invocations. Active-lease wakes return aggregate progress without spending retries. An expired lease permits takeover after a crash; revision fencing rejects former owners. The runner accepts injected `clock`, `leaseMs` (default 60 seconds), and `token` for deterministic verification. Production transport and QA calls require bounded wall time; configure lease duration above that bound and use the same trusted time domain for runtime checks. Lease expiry grants takeover eligibility; it is not itself an atomic cancellation. An expired operation cannot initiate a new acceptance commit. A commit initiated while unexpired may finish after the deadline only if no takeover or cancellation advances the revision first. No server-side time-conditioned CAS guarantee is claimed. Each successful stage resets its attempt count; three failed/expired attempts make an item failed, preserving finite retry budgets. Scheduling and stale/failed-task remediation belong to the private supervisor and are not implemented by this factory.
