# CONTROL-003 — private-runtime workbook intake contract v1

`private_runtime.worker` is a public-safe source package for a *separately authorized* staging worker, not a deployed Hedy bridge. It contains no provider transport, credentials, OAuth configuration, file paths, database, provider write API, or production entry point. Do not publish private checkpoint records. Only `PublicProgress` (aggregate counts) can cross back to a public controller; even opaque source IDs, digests, fingerprints, file IDs, formulas, and error text remain private. The source files and tests are synthetic-only.

## Contract and state transitions

- Runtime supplies `RuntimeScope(client="jespersen-painting", environment="staging", root_id=<opaque injected ID>)`, a `ReadProvider`, a `CellParser` matching `PARSER_VERSION`, and a governed `PrivateCheckpoint`. No real root ID belongs in this repository. This package cannot authorize the separate runtime lane.
- `ReadOnlyBoundary` allowlists exactly `list` and `read`; listing is limited to the configured root, and both listed references and read responses must claim that exact parent. It rejects out-of-root references before reading. The injected provider must itself enforce the same containment server-side (including descendants/symlinks, if ever supported), least privilege and stable snapshots; parent-ID checks in this public package are not proof of provider ancestry or authorization.
- Manifest IDs are unique before side effects. For each new item: `listed -> boundary_checked -> read_verified -> classified_adapted -> [recomputed] -> committed`. A boundary, read, digest or parser error is stored as a sanitized item failure; unknown shape is `needs_review`, never guessed. Read bytes are hashed against the **inventory-supplied original-byte SHA-256** before parsing. Bytes are transient, never in a checkpoint or public progress. A failed or review item is terminal for this pipeline version, not automatically retried.
- Uses `job_cost.inventory.InventoryRecord` (opaque `src_` ID and immutable SHA-256), `job_cost.batch.CheckpointKey`/`run_batch` (classification + adapter dispatch), `job_cost.shape_classifier` signature, `job_cost.schema.JobCostDocument`, and `job_cost.calculation.recompute`. The current parser/adapters are **invented synthetic layouts only**. Category coverage is not asserted by these adapters: recomputation is called with no coverage assertions, so metrics stay unknown rather than inventing financial truth. Source facts/formulas remain separate from derived facts. No real workbook coverage is implied.
- `PrivateRecord` binds the runtime scope, worker version, batch pipeline version, source ID/hash, provider ID, terminal result, structural fingerprint, parser/adapter evidence through `ItemResult`, and calculation version when computed. A governed checkpoint must provide **atomic** `put_if_absent`, enforce unique source IDs across hashes and file IDs, and retain private audit history; `MemoryPrivateCheckpoint` is a single-writer synthetic demonstration only. A restarted run with the same manifest skips terminal records and processes at most `limit` new entries. Changes of source digest or file ID under the same ID fail closed. Manifest ordering is provider-defined and must be stable for predictable `limit` progress. An interrupted read/parse can be attempted again because only terminal records are checkpointed; production-grade retry/timeout limits and telemetry require a separately authorized runtime design.

The tests in `tests/test_private_runtime_worker.py` use invented byte strings, IDs and cell data. They exercise bounded restart/replay, identity/digest guards, boundary and write-operation rejection, unknown shape, failure isolation, and private/public projection. They do not verify live Hedy, Drive, Nango, real workbooks, provider permissions, governed persistence, or staging acceptance. Rollback: remove this package and its synthetic tests/documentation only; no external state is modified.
