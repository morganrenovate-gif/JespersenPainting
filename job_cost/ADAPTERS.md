# DATA-004: synthetic workbook adapter foundation (repository-only)

`job_cost.adapters` takes invented `SyntheticItem` structures and extracted `SyntheticCell` values in memory. `process_item` runs the existing exact-match classifier, chooses one explicit adapter version for `synthetic-ledger/v1` or `synthetic-ledger/v2`, and emits a `job_cost.schema.JobCostDocument` with that adapter version in `SourceWorkbook`. These two layouts are synthetic exemplars only, **not** known Jespersen workbook formats. The layouts differ in header and hours-cell positions. They intentionally require exactly one hours cell and one source-reported total cell; other cells and invalid numbers fail the item instead of being ignored. No workbook bytes are read here.

The adapter protocol requires `shape_version`, `version`, and `adapt(item, workbook) -> JobCostDocument`. It must return source facts attributable to the supplied workbook. The example adapters retain the literal total and formula text as source evidence; hours are normalized separately to Decimal, with no calculated metric or source-total replacement. All other schema fields are explicitly `missing`, never implicitly zero. A supplied digest is only a contract value, **not** a hash computed or verified by this module. The caller must supply truthful complete structure metadata and an original-byte digest; this module cannot attest to either.

A complete unregistered shape returns `needs_review/unrecognized_shape`; incomplete or invalid structural metadata returns `needs_review/insufficient_metadata`. Both carry a `SourceWorkbook` with unknown shape and **no selected adapter** or document. Invalid source identity/hash, malformed selected-shape cells, and adapter errors return `failed/item_error` with no document. Error results deliberately do not include raw cell text or exception messages. `process_items` processes independently in input order and returns one result per item; it is not a resumable, idempotent, stored or progress-tracked batch importer. The failed item does not prevent handling another item. Consumers must not treat a review result or a failed item as an imported document.

This is not real-workbook coverage, corpus ingestion, manual reconciliation, runtime integration, deployed acceptance, or financial recomputation. No provider access, workbook scanner, storage, replay/checkpointing or production behavior is included. Real evidence must stay in governed storage; future validated adapters require authorized private-runtime review and independent QA. The tests are invented synthetic examples only; a trusted workflow can run `python -m unittest discover -s tests`. Rollback: remove `job_cost/adapters.py`, `tests/test_job_cost_adapters.py`, and this document; no migration or external state is involved.
