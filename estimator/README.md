# EST-001 painting takeoff taxonomy (repository-only)

`estimator.taxonomy` declares the versioned `painting-takeoff/v1` vocabulary for painting scope classification. `PaintingScope(category, finish=None)` accepts only `walls`, `ceilings`, `doors`, `trim`, `cabinets`, or `exterior`. `exterior` is a broad scope category, not a measured exterior surface type. `FinishRequirement(finish_type, sheen=None)` represents an explicit *declared requirement*: finish types are `paint`, `stain`, `clear_coat`; optional sheens are `flat`, `matte`, `eggshell`, `satin`, `semi_gloss`, `gloss`. Omitted finish or sheen means unspecified, not an assumed default. These exact lowercase identifiers are stable for v1; semantic or identifier changes require a new taxonomy version. Unsupported identifiers and malformed types raise `ValueError` rather than being guessed or silently normalized.

These immutable values are vocabulary only: they do not contain plan evidence, provenance, quantities, surface measurements, labor, material usage, pricing, or financial truth. A declared finish does not certify applicability to any surface or feasibility of a finish/sheen combination. Later interpretation, review, and deterministic measurement rules must remain separate; no extraction or calculation is implemented here. The synthetic-only tests in `tests/test_estimator_taxonomy.py` check identifiers, categories, finishes, omission, and invalid inputs. This module does **not** establish real plan coverage, a completed-job backtest, or estimator/backtest acceptance. No user-facing surface, provider read, deployment, or migration is included.
